I am a member of the [**Cozy Inn**](https://t.me/cozy_inn) team, responsible for the **Deltarune** localization *(as of November 19, 2025)*. My work spans several areas—from programming and web development to graphics, animation, and sound. Below are the main roles I have performed in the project:

### Technical Part

Automated workflows in the project repository. Wrote scripts to automate patch builds.

Worked with the game using **Undertale Mod Tool**, making changes to the GML code to fully support the Russian localization.

This includes:
- adjusting text and UI;
- fixing compatibility issues;
- reworking mechanics for the purpose of Russification.

### Project Website Developer

Created the [official translation website](https://deltaruna.ru) (frontend + backend), including all technical aspects:
- **Svelte 5** for frontend and backend;
- **MongoDB** for data storage;
- **SFTP** for uploading builds to the file server;
- the website's architecture and all code were written by me;
- the design was created by [**Sasikqq**](https://bento.me/sasik);
- the website is hosted on the [vercel](https://vercel.com) service;

### Graphical Patcher Developer

Wrote a patcher with a graphical interface in the style of typical installers:
- convenient drag-and-drop feature for the game icon to locate necessary files;
- interface built with **Python + PySide6 (Qt)**;
- the patcher core is written in **C#** using **Undertale Mod Lib** *(For details, see the GMS-UTML-Patcher document)*.

### Drawing Graphics for the Russian Language

Drew Russian glyphs and adapted the game's graphical elements for the Russian language.
Used:
- **Adobe Illustrator**;
- **Adobe Photoshop**;
- **Aseprite**.
  The work involved adapting pixel art, UI elements, and special effects.

### Animated Text Special Effects

Recreated the text effects of Mr. A. N. Tenna *(Mr. Ant Tenna in the original)* using **Adobe After Effects**, preserving the style of the original game.

### Sound Design

In **FL Studio**, recreated the original sound effects, applying them to the Russian voiceover.
